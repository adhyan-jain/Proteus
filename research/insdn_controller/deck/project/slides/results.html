Be precise about the intervals: they come from re-shuffling which captures fall in which fold and from model initialisation, on the same 44 captures. They are not intervals over new testbeds. We also ran a capture-level cluster bootstrap on pooled window counts; it is in the result file (A_capture_cluster_bootstrap) and is wider, for example 0.926 to 0.995 for the MLP. No tree-model baseline: the XGBoost install failed on the network and GPU-only training rules out substituting a CPU model. Robustness is in the paper: 5 s windows give 0.958; the broader IP-based label rule gives 0.881 (1 s) with the same ranking against thresholds.
