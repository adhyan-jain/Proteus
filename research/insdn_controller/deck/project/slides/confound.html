So capture-level scores on InSDN can credit session recognition as detection. We report within-session numbers as the conservative result.

This is the point to own before the professor raises it. Benign and attack traffic were recorded in separate sessions, so a model can partly learn the session. We measured that directly, with controller reply counts removed and a majority-class baseline. It stays high, so the confound is real and we do not claim it is removed. The within-session test helps because both classes share one session there, and we restrict to windows that contain at least one PacketIn so empty windows cannot be scored trivially. Honest limit: even the within-session figure is not a proof that nothing session-specific remains. The strongest fix is a testbed where benign and attack traffic are interleaved in one session; that is the live-SDN extension.
