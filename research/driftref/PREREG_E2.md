# PREREG E2 — Generalisation: is the stale-reference defect a property of the DESIGN, not of this RF?

Written 2026-10-17 after E1 results were seen (E1: stale reference + system-adapted RF => FAR 0.56 LOOP /
1.00 DAEMON on unchanged traffic; recomputed reference => ~0). E2 is therefore CONFIRMATORY OF A
HYPOTHESIS GENERATED BY E1, with its design fixed here before any E2 result exists.
E1 caveat carried over: its H2 (validity "CI contains alpha") failed on the letter because tied
confidences make the RF's KS test conservative (FAR 0 <= alpha). E2 adds MLPs whose confidences are less
tied; validity here is judged as "FAR upper CI <= alpha + 0.02" (stated now, not after the fact).

## Design pattern under test (minimal industry version)
"Record the distribution of a model's max-softmax confidence at deployment time (reference). Monitor
windows of live traffic with a two-sample KS test against that reference. On alarm, retrain on a
bounded recent buffer and redeploy. The reference is not recomputed for the new model."
Exactly the pattern in `proteus/closed_loop_full.py`, but with the learner and the retraining-set
size as the experimental factors. Traffic is stationary BY CONSTRUCTION (IID windows from STREAM).

## Factors
- Family (3): RF-100 (sklearn, CPU); MLP-small (2 hidden x 64); MLP-large (2 hidden x 512)
  (PyTorch, CUDA required — script asserts it; CLAUDE.md rule 1).
- Retraining-set size N in {5,000; 25,000; 100,000; 200,000} (row draws from TRAIN, new draw and
  new seed vs the reference model). N=200,000 is the equivalent-retrain CONTROL.
- Reference model: same family, trained on 200,000 TRAIN rows. Reference sample = its confidences on
  20,000 HOLD rows (unbiased; this removes the in-sample factor that E1 showed matters).
- Stale: reference of the reference model. Fresh (repair): the serving model's own confidences on the
  same HOLD rows.
- MLP: inputs sign(x)*log1p(|x|), standardised with train statistics, clipped to +-10; 20 epochs,
  Adam lr 1e-3, batch 512, no early stopping; CE loss. Same recipe for every N.
- Data/splits/seeds: as E1 (CICIDS2017 Mon-Thu, group-hash split, seeds 0..4). Windows W=1000,
  300 per cell, alpha=0.05, `proteus.drift.detect_drift`. Positive control: Friday windows (100),
  serving model N=200,000, fresh reference.

## Measures and thresholds (fixed now)
FAR per (family, N, stale|fresh); two-level cluster bootstrap (seeds, then windows), 5,000 reps.
- H6 PRIMARY (design-level violation): at N=25,000, stale FAR lower CI bound > 2*alpha (0.10) in
  AT LEAST 2 of 3 families.
- H7 (validity): at N=200,000, stale FAR upper CI <= alpha + 0.02 in all 3 families.
- H8 (repair): fresh FAR upper CI <= alpha + 0.02 for every (family, N).
- H9 (sensitivity): positive-control FAR >= 0.95 in all 3 families.
- If H7 or H9 fails, the corresponding family's other results are reported as INVALID for that family.
- Reported but NOT thresholded (EXPLORATORY): stale FAR vs N (dose-response), accuracy / macro-F1 /
  mean confidence of each model on HOLD, and the correlation between |mean-confidence gap| and FAR.

## Stopping
Fixed design; no seeds added or dropped after results. Nulls reported as nulls.

## Decision rule for the project (fixed now)
If H6 fails: the E1 effect is specific to RF-on-small-buffer; no design-level claim; close research.
If H6 passes: the defect is a property of the pattern; STILL not claimed as novel until the prior-art
note (step 8) is written; the existing search found per-model-version baselines recommended in
practitioner guidance, so the likely framing is "measured, quantified instance of known practice".
