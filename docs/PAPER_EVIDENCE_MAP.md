## Figures

`paper/figures/` contains all three publication figures generated by `paper/generate_figures.py`:
1. `stage3_baseline_vs_static.png` — Stage 3 baseline vs static augmentation comparison.
2. `stage4_fidelity_gate.png` — Stage 4 MMD fidelity gate admission/rejection performance.
3. `stage7_macro_f1_series.png` — Stage 7 temporal drift macro-F1 progression across 16 replay windows (validated post-leakage-fix).
Running it is the single highest-value next step for the paper's visual completeness:
```bash
cd /home/adhyan/Desktop/Proteus
.venv/bin/python -m pip install matplotlib   # or: TMPDIR=.uv-tmp uv pip install --python .venv/bin/python matplotlib
.venv/bin/python paper/generate_figures.py
```
This produces `stage3_baseline_vs_static.png` and `stage4_fidelity_gate.png` immediately (both
backed entirely by already-written numbers). It will refuse to produce
`stage7_macro_f1_series.png` until `results/stage7_evaluation.json` is regenerated with the
leakage fix (pass `--allow-stale` only to inspect the known-invalid numbers, never for the final
paper).
